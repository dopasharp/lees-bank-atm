# LEE'S BANK ATM

아이패드용 ATM 화면.

- 모든 화면 아래에 이전 · 홈으로 · 다음 버튼이 있어요.
- 비밀번호 화면은 아무 숫자나 넣거나 아무것도 안 넣고 다음을 눌러도 넘어가요.
- 현금 인출: 금액(전액 뽑기만 가능, 다른 금액은 "금액이 맞지 않아 출금할 수 없습니다") → 거래 확인 → 카드 투입(맨 마지막) → 꼭 10초 기다리면 "미션 성공!! 생일 축하합니다!" 축하 화면 (카드 화면에서는 다음 버튼이 안 눌려요). 시작 잔액 1,000,000원.
- 입금은 끝까지 진행하면 "입금은 불가능합니다!!!" 안내가 뜨고 잔액은 그대로예요.
- 키보드: 숫자 입력, Enter/→ 다음, ← 이전, Esc 홈, ⌫ 지우기.
